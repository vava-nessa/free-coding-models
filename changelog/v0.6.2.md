# Changelog v0.6.2 - 2026-11-22

### Changed
- Re-audited all 24 providers against their official catalogs, pricing pages and model cards. Models with unresolved access or benchmark evidence remain pending rather than being presented as newly verified.
- Updated provider access information: Pollinations uses one-time Quest credits, Vercel requires a payment method for monthly credits, Runcrate requires an eligible GitHub account and shares a weekly allowance, and SiliconFlow requires real-name verification.
- Clarified that OpenCode's free promotions require its client and that Ollama's publicly undocumented starter allowance does not establish free access to every cloud model.
- Retired Mistral, Codestral and Novita from the active free catalog while preserving their configuration metadata for existing installations.

### Added
- Added newly verified free routes from the provider audit, using hosted context limits. Unpublished SWE-bench Verified scores remain unknown and their tiers are provisional.

### Fixed
- Removed retired or no-longer-free model routes and embedding or decision models that cannot serve coding chat requests.
- Corrected GPT OSS 20B scores, Muse Glimmer and Xing4.0 rankings, and the Scaleway DeepSeek V4.1 Flash identifier using published evidence.
- Removed incorrect shutdown dates from Gemini 2.5 Flash Lite and OVHcloud Mistral Small 3.2; annotated announced OVHcloud retirements.
- Made OpenRouter live discovery reuse audited catalog ratings so it cannot replace them with a stale second score table. Unknown discoveries no longer receive a fabricated benchmark score.
- Synchronized the website catalog and provider documentation with the shared source data, updated the displayed version, and replaced misleading GitHub placeholder branding with each gateway name.
